Findings and limitations

  • The completed drawings use genuine Pen-created Bezier curves. Session review checked mixed paths, not merely the presence of one curved segment. The straight segments follow straight reference edges; no faceted curve approximation was found in completed drawings. Native path records confirm stroke None for the completed drawings. IoU and boundary errors are unaligned observations, not pass thresholds.
  • The first two Pi Codex-computer-use actors stopped early and said so. Their unchanged exports lack the required blue shape; the second also has no genuine curve. Only one of nine Pen drags across those two sessions produced direction handles. Shift_L+c selected Scissors instead of the intended modified shortcut; the first run's Control_L+z did not undo its anchor. These are observations, not proof of a universal backend limitation. The third trial used the same drag call form, continued after failed handles and repaired seven anchors with GUI smoothing and handle drags. No causal explanation for the inconsistent drag behavior is established.
  • The first Claude CUA actor used relative screenshot destinations resolved by the daemon in the home directory. It overwrote pre-existing C:/Users/13982/cp.png twice. The original automatic conduct check missed this runtime-side write. Parent review records a safeguard violation and excludes the slot, while preserving its method-pass review and automatic result. Four proven-new screenshots (s.png, a.png, b.png, x.png) were archived and removed. The overwritten cp.png path is retained and its current bytes archived; no verified original-byte backup is available, so the original was not restored.
  • Full-session review found silent metric omissions in 03-Pi CUA (exec(open(...).read()) helpers) and 03-Pi Codex computer use (var-declared JavaScript helpers). Both original ledgers incorrectly claimed complete attribution. The reviewed aggregate masks their code-token/share and call-count/duration fields; the raw aggregate and original metrics remain intact. Consequently no configuration has a complete successful-cohort code-share or computer-use-duration average in this round. API-token and quality averages remain available.
  • Several other source transformations exceed the static metric extractor. Unknown code share and call-duration averages remain withheld rather than reconstructed selectively. In 01-Claude CUA, review found two missing helper execution spans and two query-only calls in its partial ledger. In 03-Claude CUA, a status query was counted while describe was excluded. In 03-Pi ACU, one 30-second host-call timeout was dominated by a home-directory search; top-level mixed-call duration includes that overhead. Raw ledgers and review notes remain intact.
  • Illustrator was reset to the documented blank document/view/snapping state, not a pristine application profile. Later actors could use the cyan Recent Colors swatch left by earlier trials. This shared application state limits claims of complete environmental isolation. Sessions, prompts and selected tool configurations were isolated.
  • Pi used openai-codex/gpt-6-astra, low reasoning, across ACU, CUA and Codex computer use. Claude Code used claude-opus-5-5, low effort, across ACU and CUA. The native computer-use transport was the default SDK helper. The protocol was v0.11, drawing-only with fill #00AEEF and no stroke. Normal retry and compaction were enabled; no parent coaching, mid-trial repair or source/skill change occurred.
