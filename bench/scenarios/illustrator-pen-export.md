# Adobe Illustrator Pen and Export v0.5

Recreate the icon shown in Cloud9-Reference.jpg using Adobe Illustrator's Pen tool in the already-open Cloud9-Pen-Starter.ai. It has one blank 800 × 800-point RGB artboard and one unlocked Drawing layer. Approximate the reference's shape, scale, and placement.

Choose anchor and handle positions visually. Code may map and replay your literal positions, but must not generate them from the image or a parametric shape. Use the Pen tool's desktop controls, not Image Trace, imported vectors, raster substitution, or Illustrator scripting. You may place the supplied JPEG as a tracing aid; remove it before exporting.

After drawing, select fill #00AEEF, no stroke, and 100% opacity.

Export Cloud9-Recreated.png in the workspace through Export As: PNG, Use Artboards (the single artboard), 72 ppi, Art Optimized (Supersampling), White background, Interlaced off. The output must be an opaque 800 × 800 PNG. If Illustrator appends an artboard suffix, rename the exported file to Cloud9-Recreated.png. The PNG is the only deliverable. No separate editable copy or report file is needed. Once it is exported, stop.
