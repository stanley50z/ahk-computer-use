# Adobe Illustrator Pen and Export v0.6

Workspace: <WORKSPACE>
Scratch folder: <WORKSPACE>/scratch
Final output: <WORKSPACE>/Cloud9-Recreated.png

Recreate the shape in Cloud9-Reference.png using the Pen tool in the already-open Cloud9-Pen-Starter.ai, then export the result as a PNG. Use the supplied computer-use tool for every interaction with Adobe Illustrator.

Set the fill color to #00AEEF.

Export to the final output path through Export As with these settings:
- PNG
- Use Artboards
- 72 ppi
- Art Optimized (Supersampling)
- White background
- Interlaced off

Only the PNG is required. Stop after exporting.
